# Telegram Stars Payment Gateway

Бот-«шлюз»: доступ к AI-аналитике даётся **только после оплаты подписки**. Оплата — Telegram Stars (или тестовый режим ЮKassa). Статус хранится в SQLite, доступ снимается автоматически, когда подписка истекает.

По ТЗ: aiogram (обработка `PreCheckoutQuery` и `SuccessfulPayment`) + SQLite.

## Команды

| Команда | Что делает |
|---|---|
| `/subscribe` | выбрать тариф и оплатить (инлайн-кнопки) |
| `/trial` | бесплатный пробный период, один раз на пользователя |
| `/status` | статус и дата окончания подписки |
| `/payments` | журнал платежей |
| `/refund` | возврат последнего платежа Stars + отзыв доступа |
| `/unsubscribe` | отключить автопродление (если включено) |
| `/analyze ...` | та самая AI-аналитика (доступна только оплатившим) |

## Тарифы

Задаются в `config.py` и показываются кнопками:

- **starter** — 50 ⭐ / 30 дней;
- **pro** — 120 ⭐ / 90 дней;
- **business** — 200 ⭐ / 180 дней.

## Как это работает

1. Пользователь жмёт тариф → бот отправляет инвойс через `send_invoice`;
2. Telegram сам показывает платёжное окно (Stars или банковская карта через ЮKassa);
3. Приходит `PreCheckoutQuery` — мы его подтверждаем (или отклоняем, если что-то не так);
4. После успешной оплаты приходит `SuccessfulPayment` → включаем подписку, пишем в журнал;
5. **Серверная валидация payload**: цену и тариф мы не берём из данных кнопки, а пересобираем на сервере из `payload` — подменить цену в инвойсе не выйдет;
6. `/refund` возвращает Stars через `refund_star_payment` и отзывает доступ.

`STAR_PAYMENTS=0` переключает на тестовый режим ЮKassa (`YOOKASSA_PROVIDER_TOKEN` выдаёт @BotFather в меню Payments).

## Запуск

```bash
python -m venv .venv
pip install -r requirements.txt
export WB_BOT_TOKEN=123456:ABC...
export STAR_PAYMENTS=1
python bot.py
```

На Windows — `run_bot4.cmd`. Демо-режима здесь нет: платёж в тестовом окружении Telegram проходит «по-настоящему», но без списаний — это особенность тестового режима платежей, денег не нужно.

## Из чего состоит

```
bot.py          — инвойсы, PreCheckoutQuery, SuccessfulPayment, команды
ai_service.py   — «заглушка» AI-аналитики (в учебной связке импортирует Проект 2)
db.py           — подписки, журнал платежей, used_trial, refund_payment
config.py       — тарифы (TIERS), парсинг payload, настройки
middlewares.py  — троттлинг и логирование
tests/          — 5 тестов (парсинг payload, подписки, возвраты, журнал)
```
